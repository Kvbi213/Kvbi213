## [+] Zaimplementowane funkcjonalności & Poprawki
- **Eliminacja błędu API Vercel (Maximum retries exceeded):**
  - Przeniesiono źródło repozytoriów i statystyk z przeciążonej instancji `sigma-five` na w pełni sprawną, zweryfikowaną instancję `eight-theta`.
  - OmniDash Repo Card, GitHub Overall Stats oraz Top Languages ładują się stabilnie z poprawnym kodem HTTP 200.
- **Eliminacja problemu z niewidocznymi ikonami (1em collapse):**
  - Zidentyfikowano przyczynę: zewnętrzne SVG z Iconify posiadały jednostkę `1em`, która w tagach `<img>` w przeglądarkach Chromium i na GitHubie zapadała się do 0x0 pikseli.
  - Pobrano i zapisano kompletny zestaw ikon lokalnie w katalogu `assets/icons/` ze sztywnym atrybutem `viewBox="0 0 24 24" width="24" height="24"`.
  - Wszystkie ikony działają teraz natywnie w trybie offline w `preview.html` oraz po wypchnięciu do repozytorium GitHub.
- **Optymalizacja preview.html:**
  - Wdrożono natychmiastowe ładowanie zawartości bez blokad polityki CORS dla protokołu `file://`.
